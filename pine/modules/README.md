# Modules

Reserved for optional future extraction of AlphaFX AI engines into separate Pine include files.

Current release (`1.0.0`) ships as a single production script:

[`../AlphaFX_AI.pine`](../AlphaFX_AI.pine)

Do not split engines until:

1. TradingView include/workflow needs are clear
2. Engine APIs remain stable in production use
3. Split improves maintainability without harming compile time or readability
