# Changelog

All notable changes to AlphaFX AI are documented in this file.

## 1.0.0

### Release

- First professional release
- Full SMC engine pipeline (Phases 1–10) marked stable for production use on TradingView

### Includes

- Trend, Structure, BOS/CHoCH
- Order Blocks, Fair Value Gaps, Liquidity
- Sessions, Multi-Timeframe, Confidence, Risk
- Dashboard, alerts, and project documentation

### Notes

- Confidence measures confluence quality, not win probability
- Risk levels are educational guidance, not trade execution
- Continue validation with checklists in `tests/` as markets and settings evolve
